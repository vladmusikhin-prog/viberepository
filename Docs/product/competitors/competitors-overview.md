# Competitors — Polymarket Signals

Дата обновления: 2026-04-11 (0xInsider: pricing, Trade Reports, фильтры терминала, Datasets, **Account / Redeem code**, paywalls).

Ниже 5 релевантных аналогов/смежных продуктов для `Polymarket Signals` (алерты, whale-flow, мониторинг Polymarket/Kalshi).

## 1) Signal Scout

- Сайт: [https://useagentbase.dev/](https://useagentbase.dev/)
- Что делает: real-time алерты по новостям, которые двигают рынки Kalshi и Polymarket; добавляет AI-анализ импакта новости.
- Почему релевантен: закрывает core pain “быстро понять, что важно сейчас”, особенно через news-driven сигналы.
- Модель/позиционирование: app/tool для трейдеров prediction markets с подписками на конкретные рынки.
- Отличие от нашей гипотезы: сильнее в `news intelligence`, слабее выражен social-layer (рейтинги аналитиков/портфели идей в Telegram).

## 2) 0xInsider — Trade Alerts

- Сайт: [https://0xinsider.com/whale-alerts](https://0xinsider.com/whale-alerts)
- Что делает: отслеживает крупные трейды по Polymarket и Kalshi, показывает ленту сделок; у paid-тарифа — near real-time, фильтры и daily digest.
- Почему релевантен: прямой конкурент по `large trade / whale` сигналам.
- Модель/позиционирование: freemium (free с задержкой, insider — live-режим и терминал).
- Отличие от нашей гипотезы: фокус на trade tape/terminal; у нас потенциальный дифф — explainable alerts + social ranking в Telegram.

### Питч и воронка (лендинг, референс для Polymarket Signals)

- **Питч (суть):** когда на рынок заходит очень крупная сделка, пользователь должен **узнать об этом вовремя**; все крупные трейды по Polymarket и Kalshi — **в одном месте**, с поиском/фильтрами.  
  Англ. формулировка на сайте: *«When a trader drops $50K on a market, you should know about it.»*
- **Бесплатный крючок:** зарегистрированным free — **10 лучших сделок вчера** среди трейдеров высоких грейдов (S/A), чтобы **разогреть интерес** и показать паттерны без live-доступа.
- **Платное отличие:** Insider видит **каждую** крупную сделку **в реальном времени** + терминал/алерты (см. pricing выше).
- **Идея для нас:** тот же паттерн в Telegram — **дайджест «вчерашний топ-10»** (или топ-N) как бесплатный слой → **подписка** на live и расширенные сигналы. Зафиксировано в `Docs/product/Product Card.md` → раздел «Питч и конверсия».

### Trade Reports (терминал 0xInsider, снимок 2026-04-11)

В UI продукта отдельный блок **Trade Reports**: e-mail-дайджесты **крупных** движений — топ сделок, трендовые рынки, отмеченные трейдеры; переключатели **Daily summaries** и **Weekly recaps**; доступ после апгрейда на Insider.

**Идея для Polymarket Signals:** для paid добавить отчёты **ежедневно**, **еженедельно** и **ежемесячно** (месяц — расширение относительно референса). Подробно и с таблицей периодов: `Docs/product/Product Card.md` → «Trade reports».

### Category filter (paywall в терминале, снимок 2026-04-11)

Фильтр сделок **по категории рынка** (Politics, Crypto, Sports, Geopolitics и др.) и текст в духе «see which categories attract the most large trade activity» — только у **Insider**, для free кнопка **Category** с замком и CTA **Upgrade to Insider**.

**Идея для нас:** использовать **category filter** как мотив к подписке: бесплатно — общая лента / топ без выбора тем; платно — **только нужные категории** в алертах и отчётах. Подробно: `Docs/product/Product Card.md` → «Category filter».

### Grade filter (Large Positions, снимок 2026-04-11)

У позиций/трейдеров — **буквенные грейды** (S…F) с пояснением качества аккаунта; фильтры по грейду и полный список крупных позиций частично **за paywall** («Unlock all … positions», **Upgrade to Insider**).

**Идея для нас:** аналогичная или **своя** градация аккаунтов + **опционально** только в платной версии — фильтрация сигналов по качеству контрагента. Методика и free/paid split **не зафиксированы**. Подробно: `Docs/product/Product Card.md` → «Grade filter».

### Portfolio % filter (терминал 0xInsider, снимок 2026-04-11)

Фильтр по **доле портфеля** в одной сделке (25% / 50% / 75% / 100% all-in), смысл: выше % — сильнее уверенность трейдера; **paywalled**, CTA **Upgrade to Insider**.

**Идея для нас:** показывать **% портфеля в самом алерте** (если данные есть) и/или давать **расширенный сигнал и фильтры** в paid — см. `Docs/product/Product Card.md` → «Portfolio % filter».

### Datasets / «сырые данные Polymarket» (0xinsider.com/datasets, снимок 2026-04-11)

На маркетинговой странице **Datasets** сформулирована **инженерная проблема**: сырой **CLOB API** Polymarket отдаёт логи, которые плохо интерпретировать без пайплайна; нужно сшивать **BUY / SELL / MERGE / REDEEM**, считать cost basis при **partial fills**, обрабатывать сплиты/rebates/позиции без redemption; поля вроде **`size` как число шаров, не USDC**, ненадёжные даты, «тихое» исчезновение проигрышных позиций с учёта; команды тратят **недели** на пайплайн до анализа.

**Для нашего продукта:** учитывать как **риск реализации и качества сигналов** — см. `Docs/product/Product Card.md` → «Проблема данных (Polymarket / CLOB)». Референс позиционирует готовый **export в JSON** «в один шаг»; у нас — явный слой нормализации + осторожность в алертах при неполных данных.

### Account — Redeem / invite code (0xinsider.com/account, снимок 2026-04-11)

В настройках аккаунта блок **Redeem Code**: ввод **invite code**, **Apply**; копирайт про немедленное обновление доступа/сессии после активации кода.

**Идея для Polymarket Signals:** **промокод + реферальная мотивация** (пригласившему — **% на баланс** при оплате друга; приглашённому — бонус входа). Зафиксировано в `Docs/product/Product Card.md` → «Redeem code и реферальная выгода».

## Короткий вывод по конкурентному полю

- Ниша `whale alerts` уже конкурентна (включая free и OSS).
- Более редкий дифференциатор — не просто “кто купил/продал”, а `что это значит`, `насколько это надежно` и `кому из аналитиков можно доверять`.
- Для MVP имеет смысл делать акцент на:
  1. explainable alerts (сигнал + контекст + confidence),
  2. скорость доставки в Telegram,
  3. social trust primitives (track record/leaderboard/профили).
